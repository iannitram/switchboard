Today all of it lives in `crates/cli/src/cli.rs`:

Build this:
1. `crates/core/src/read/star.rs` (declare it in `crates/core/src/read/mod.rs`):
   - `pub struct StarFacts` and `pub struct StarFactsPr` with the fields and types `Star` and `StarPr` have today. The names are new because `sky::model` already has a `Star` and a `StarPr`.
   - `pub struct StarAnswer { pub star: Option<StarFacts>, pub no_snapshot: bool, pub warnings: Vec<Warning> }`.
   - `pub fn load(data: &Path, ledger: Option<&[PathBuf]>, repo: &str, number: u64) -> Result<StarAnswer, CoreError>`.
   - Snapshots come through `read::snapshots` ({{#r-waiting}}). No snapshot read gives `star: None, no_snapshot: true`, with the warnings.
   - The repo is resolved with `switchboard_core::guarded::resolve_repo` from {{#w-core}} (`resolve_repo(repo, known) -> Result<Option<&str>, CoreError>`; `known` is the repos of the snapshots read). An unknown repo (`Ok(None)`) or an unknown issue number gives `star: None, no_snapshot: false`. A bare name that matches two owners is that function's `CoreError::Refused` (`<repo> matches <a> and <b>; name it as <owner>/<repo>`), returned as the error. No new `CoreError` variant.
   - The job comes from `joblog::read_ledger` and `sky::jobs::in_flight`, not a second ledger reader; `job_text` in jobs.rs stays private. `ledger` is the file list the face found, as in {{#r-sky}}; `None` means the job was not read (outer `None`). A ledger that does not read is one warning (same `file` and `reason` rule as {{#r-sky}}) and the job is the outer `None`, which `star_json` and `star_text` already know how to show. Today this fails `switchboard star` and the MCP `star` tool; by owner ruling (2026-11-26) the Star is shown without its job in every face. The PR body lists this as a deliberate change. No existing test pins the old failure: no test under `crates/cli/tests/`, and no in-file test of `crates/cli/src/`, runs `star` against a ledger that does not read, so no test is edited for it. A test through the built binary is not added, for the reason {{#r-sky}} gives (`joblog::ledger_files` lists only regular files); the tests of `read::star::load` in Done when 2 are the proof.
